# 텔레그램 버스봇

웹 챗봇과 같은 버스봇을 텔레그램에서 쓰게 해 주는 봇이다. 질문 분류, 도착 조회(MCP), 정책 검색(RAG)은 모두
챗봇 서버(`main.py`)가 하고, 이 폴더의 봇은 텔레그램 메시지와 챗봇 API(`/api/chat`, `/api/arrivals`) 사이의 변환만 맡는다.

```
텔레그램 앱 ⇄ Telegram Bot API ⇄ telegram_bot (롱 폴링) ⇄ 챗봇 서버 :8000 ⇄ MCP 서버 :8765
```

## 실행

봇 전용 패키지(표 그림용 Pillow)를 설치한다.

```bash
pip install -r telegram_bot/requirements.txt
```

MCP 서버와 챗봇 서버를 먼저 띄운 뒤, 프로젝트 루트에서 실행한다.

```bash
python bus_server.py
uvicorn main:app --port 8000
python -m telegram_bot
```

롱 폴링 방식이라 공개 주소나 HTTPS, 방화벽 설정이 필요 없다. 같은 토큰으로 봇을 두 곳에서 동시에 띄우면
텔레그램이 409 오류를 돌려주고 봇이 종료된다.

## 설정 (.env)

| 이름 | 필수 | 설명 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | 예 | BotFather에서 받은 토큰 |
| `CHATBOT_URL` | | 챗봇 서버 주소 (기본 `http://127.0.0.1:8000`) |
| `TELEGRAM_TABLE_FONT` | | 표 그림에 쓸 한글 글꼴 파일 경로. 비우면 맑은 고딕(Windows), 나눔고딕·Noto CJK(리눅스), Apple SD 고딕(macOS) 순으로 찾는다 |
| `TELEGRAM_ALLOWED_USERS` | | 봇을 쓸 수 있는 텔레그램 사용자 ID (쉼표로 구분). 비우면 누구나 쓸 수 있다. 허용되지 않은 사람이 말을 걸면 그 사람의 ID를 알려 주므로, 그 값을 여기에 넣으면 된다 |

봇 주소를 아는 사람은 누구나 질문할 수 있고 그만큼 AI 모델 비용이 든다. 공개하지 않을 거라면 `TELEGRAM_ALLOWED_USERS`를 채워 두는 게 좋다.

## 쓰는 법

| 동작 | 결과 |
|---|---|
| `/start` | 인사와 대표 질문 버튼 (도착 2개, 이용 방법 10개) |
| 정류소 이름 보내기 (예: 미금역) | 후보가 여러 곳이면 **후보 표 그림**(번호, 정류소, 다음 정류장, 시군, 정류소번호)과 고르기 버튼. 버튼을 누르면 정류소 ID로 바로 조회 |
| 정류소번호 보내기 (예: 7079) | **도착 표 그림** (노선, 방면, 도착 예정, 다음 차, 차량). 2분 이내 도착은 빨간색 |
| 도착 표의 ↻ 새로고침 | AI를 거치지 않고 도착 정보만 다시 받아 그 사진을 새 표로 바꾼다 |
| 이용 방법 질문 (예: 환승 몇 분 안에?) | 문서 근거 답변과 출처 링크, "다른 질문 보기" 버튼 |
| `/reset` | 이 채팅방의 대화 기록 지우기 |

## 구현 메모

- `bot.py`: Telegram Bot API를 `httpx`로 직접 부른다 (추가 패키지 없음). 업데이트마다 작업을 따로 띄워 느린 질문이 다른 채팅방을 막지 않게 하고, 같은 채팅방의 질문은 잠금으로 순서대로 처리한다.
- `table_image.py`: 표를 PNG로 그린다 (Pillow, 2배 해상도). 웹과 같은 열 정의를 쓰고, 정류소 ID 칸은 빼고(버튼이 대신 씀), 긴 이름은 칸 안에서 줄바꿈한다. 텔레그램 메시지에는 표 서식이 없어서 그림으로 보낸다.
- `render.py`: 사진 설명(caption), 버튼, 정책 답변을 텔레그램 HTML로 만든다. 모든 값은 이스케이프한다. 한글 글꼴이 없거나 그림 전송에 실패하면 같은 내용을 글자 목록으로 보낸다.
- 대화 기록은 채팅방마다 최근 6턴만 메모리에 둔다 (봇을 다시 켜면 비워짐). 웹과 같이 표의 평문(정류소 ID 포함)도 기록에 넣어, "3번"처럼 번호로 골라도 알아듣는다.
- 챗봇 서버에는 `client: "telegram"`으로 보내 LangSmith에서 `source:telegram`으로 구분된다. 대화 ID는 텔레그램 채팅 ID의 해시(`tg-…`)를 쓴다.
- 요청 URL에 토큰이 들어가므로 `httpx` 요청 로그는 끈다.
- 즐겨찾기는 웹 로그인(Google) 전용이라 텔레그램에서는 아직 지원하지 않는다.
